# 아테네 학당 (1509–1511)

라파엘로의 벽화 「아테네 학당」 속 고대 철학자와 학자 23명을 만나 보는 인터랙티브 뷰어입니다.
[제5차 솔베이 회의(1927)](https://github.com/jihye84/solvay)의 고대 철학 버전입니다.

- **설명 모드**: 얼굴에 마우스를 올리면 이름, 누르면 설명과 음성이 나옵니다. (모바일: 한 번 탭하면 이름, 다시 탭하면 설명)
- **게임 모드**: 무작위로 나오는 10명을 그림에서 찾습니다. 틀린 문제만 다시 풀 수 있습니다.

## 인물 식별 기준
영어·독일어·이탈리아어 위키백과와 미술사 해설을 교차 검토해 학계에서 널리 받아들여지는 안을 따랐습니다. 정체가 엇갈리는 인물은 이름에 (추정)을 붙이고 설명에 다른 학설을 적었습니다. 근거가 약한 대중적 설(예: 흰 옷의 인물 = 히파티아)은 설명에서 그렇게 밝혔습니다.

플라톤·아리스토텔레스 양옆 무리처럼 학계에서 이름이 정해지지 않은 인물 가운데, 19세기 연구(파사반트, 1839)나 널리 쓰이는 해설에 이름이 나오는 5명은 "(19세기 해석)" 또는 "(대중적 해석)"을 붙여 설명 모드에만 넣었습니다. 게임 문제로는 나오지 않습니다(`data.js`의 `oldView: true`).

## 그림
